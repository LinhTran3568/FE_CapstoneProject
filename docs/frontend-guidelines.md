# Capstone FE Frontend Guidelines

## Design Tokens & Theme
- **Navy Foundation**: `#0b0f19` (background), `#161e2e` (surface card), `#1e293b` (border)
- **Cyan Primary**: `#06b6d4` / `#0ea5e9` (accent action)

## Coding Conventions
1. **Strict TypeScript**: Type safety across monorepo (`npm run typecheck`).
2. **Modular Architecture**: Separate components, pages, stores, and API layer cleanly.
